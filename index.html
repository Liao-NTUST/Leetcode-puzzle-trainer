怎麼玩 🧩

    
    
      
  1. 先讀題，再回答「觀念快問」：這題該用什麼技巧？複雜度多少？這是訓練「看到題目就想到解法」的關鍵。
    2. 
      
  2. 從左邊的積木分類拖積木到「解題函式」裡面組出演算法。參數（例如 nums）已經在「📦 變數」裡。
    3. 
      
  3. 索引都是從 0 開始；「從 a 走到 b」的迴圈不含 b，跟寫程式時一樣。
    4. 
      
  4. 需要遞迴（樹、DFS）時，到「⚙️ 函式」建立函式。函式裡「設定」過的變數是區域變數，跟 Python 規則一樣。
    5. 
      
  5. 按 ▶ 執行測試（或 Ctrl+Enter）跑所有測資。卡住了就用「印出」追蹤變數，或打開提示。
    6. 
      
  6. 「對應程式碼」分頁會把你的積木翻成 Python / JavaScript，順便熟悉真正寫出來長什麼樣。
    7. 
    

    
小技巧：在積木上按右鍵可以複製、加註解；Delete 鍵刪除；Ctrl+Z 復原。進度與積木會自動存在這台電腦的瀏覽器裡。
