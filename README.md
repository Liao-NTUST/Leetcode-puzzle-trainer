# 🧩 LeetCode 積木訓練器

用拖拉積木（不用打程式碼）來練 Blind 75 / Top Interview 150 的解題觀念。共 176 題，涵蓋兩份清單的全部題目（含 Blind 75 中的 LeetCode 付費題）。

## 使用方式

直接用瀏覽器（Chrome / Edge）打開 `index.html` 就可以，不需要安裝任何東西，也能離線使用（Blockly 已放在 `vendor/`）。

## 每題的練習流程

1. **讀題** → 回答「🧠 觀念快問」：這題該用什麼技巧？最佳時間複雜度？（答完才會揭曉技巧標籤和核心觀念）
2. **拼積木**：從左側分類把迴圈、判斷、字典、集合、堆疊、節點等積木拖進「解題函式」。
3. **▶ 執行測試**（Ctrl+Enter）：跑所有測資，看每筆的輸入 / 預期 / 你的輸出。
4. 卡住時：用「印出」積木追蹤變數、逐一打開提示，再看參考虛擬碼；真的拼不出來就按「🧩 看解答拼法」（按兩次確認）。看解答時你的積木會先存起來，按「↩ 回到我的積木」就能切回去；用解答跑測試不會記為通過。
5. **對應程式碼** 分頁會把積木翻成 LeetCode 格式的 C++（預設）/ Java / Python。

積木規則跟真正寫程式一致：索引從 0 開始、`從 a 走到 b` 不含 b、函式內設定的變數是區域變數（同 Python）。

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `js/problems.js` | 前 38 題的題庫（題目、測資、提示、虛擬碼） |
| `js/more/*.js` | 其餘題目，依主題分批：每個檔案同時放題目資料和解答積木 |
| `js/blocks.js` | 自訂積木與 JS / Python 程式碼產生器、工具箱 |
| `js/solutions.js` | 每題的解答積木（用簡短的 DSL 描述）— 新增題目時也在這裡加解答 |
| `js/typed.js` | 積木 → C++ / Java 翻譯（含型別推論、LeetCode 函式簽名） |
| `js/runner.js` | 執行積木產生的程式並比對測資（含無窮迴圈保護） |
| `js/app.js` | 介面邏輯 |

## 新增題目

在 `js/problems.js` 的 `PROBLEMS` 陣列加一個物件即可，格式參考現有題目：

- `params`：參數名稱（會自動變成積木裡的變數）
- `types`：`{ head: 'list' }` 表示鏈結串列、`{ root: 'tree' }` 表示二元樹（測資用陣列寫）
- `output`：回傳串列 / 樹時填 `'list'` / `'tree'`
- `compare`：`'unordered'`（順序不限）或 `'unorderedDeep'`（巢狀清單都不限順序）
- `resultFrom: 'arg0'`：原地修改第一個參數的題目
